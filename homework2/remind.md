# Homework 2：多項式運算系統（Polynomial）

## 41443154簡嘉亨作業說明

程式碼有使用AI做排版換行空格那些

本次作業使用 C++ 實作多項式類別，透過動態陣列儲存係數與指數，完成多項式的**加法、乘法與代入計算**，並使用運算子多載處理輸入和輸出

程式以 `Term` 表示單一項目，以 `Polynomial` 管理整個多項式。除了基本運算，也加入同次項合併、指數排序、輸入格式檢查，以及可以重複操作的中文選單

例如：

```text
A(x) = 3x^2 + 2x + 1
B(x) = x - 1
```

運算後可得到：

```text
A(x) + B(x) = 3x^2 + 3x
A(x) * B(x) = 3x^3 - x^2 - x - 1
A(2) = 17
B(2) = 1
```

## 1. 解題策略

多項式由許多「係數 × x 的次方」組成。例如 `3x^2 + 2x + 1` 可拆成下列三項：

| 係數（coef）   | 指數（exp)| 對應項目 |
|---            |---        |---|
| 3             | 2         | `3x^2` |
| 2             | 1         | `2x` |
| 1             | 0         | `1` |

我採用**只儲存非零項的動態陣列**，不需要為每一個可能的指數預留空間。程式在新增項目時，會依指數大小決定插入位置，並整理重複次方

整體處理流程如下：

1. 輸入多項式的項數、係數和指數
2. 透過 `NewTerm()` 自動排序、合併同次項，並略過係數為零的項目
3. 使用 `Add()`、`Mult()` 或 `Eval()` 完成運算
4. 使用 `operator<<` 將結果顯示為容易閱讀的多項式格式
5. 透過選單決定下一個操作，或重新輸入 A、B

## 2. 操作與輸入方式

### 輸入格式

每一個多項式在**同一行**輸入，格式為：

```text
項數 係數1 指數1 係數2 指數2 ...
```

例如：

```text
3 3 2 2 1 1 0
2 1 1 -1 0
```

第一行代表 `A(x) = 3x^2 + 2x + 1`，第二行代表 `B(x) = x - 1`

輸入規則：

- `0` 表示零多項式，沒有其他項目
- 指數必須是**非負整數**
- 係數使用 `float`，可輸入一般整數或小數
- 可以亂序輸入，也可以有相同次方，程式會自動整理
- 第一個數字代表輸入項數，後面的係數與指數必須成對出現，數量不可多或少
- 每次輸入的項數上限為 **200000 項**，這是程式設定的限制，並非多項式本身的數學上限

### 操作選單

|選項| 功能 |
|---|---|
| 1 | 顯示 A、B 多項式 |
| 2 | 多項式加法 A + B |
| 3 | 多項式乘法 A × B |
| 4 | 輸入 x，計算 A(x) |
| 5 | 輸入 x，計算 B(x) |
| 6 | 重新輸入 A |
| 7 | 重新輸入 B |
| 0 | 結束程式 |

程式啟動後會先要求輸入 A、B，之後一直顯示選單，直到輸入 `0` 才結束。若輸入的多項式或選單選項格式不正確，程式會顯示提示，並要求重新輸入

## 3. 類別與資料結構

### `Term` 類別

`Term` 負責保存一個多項式項目的資料：

```cpp
class Term {
    friend class Polynomial;
    friend ostream& operator<<(ostream& output, const Polynomial& a);
private:
    float coef; // 係數
    int exp;    // 指數
};
```

### `Polynomial` 類別

主要資料成員如下：

| 成員              | 用途 |
|---                |---|
| `Term* termArray` | 指向儲存多項式非零項的動態陣列 |
| `int capacity`    | 目前陣列能容納的項數 |
| `int terms`       | 目前實際保存的非零項數 |

例如 `capacity = 8`、`terms = 3`，表示已配置 8 格空間，但只有 3 個有效項目

`Polynomial` 透過 `friend` 宣告，讓輸入與輸出運算子可以存取需要的私有資料

## 4. 主要函式的實作說明

### 4.1 `row()`：擴充動態陣列

當 `terms == capacity` 時，表示目前的陣列已經沒有空間新增項目，程式會：

1. 將容量擴充為原本的兩倍
2. 配置新的 `Term` 陣列
3. 將原有項目複製到新陣列
4. 使用 `delete[]` 釋放舊陣列，再更新指標與容量

這種方式不必每增加一項就重新配置陣列。程式中的函式名稱是 `row()`，負責的功能是陣列擴容

### 4.2 `NewTerm()`：新增項目與合併同次項

新增項目時，程式先找到指數應該放的位置，使項目按照**指數由大到小**排列

- 如果係數是 0，直接略過。
- 如果已經有相同指數，將係數相加。
- 如果合併後係數變成 0，就刪掉該項。
- 如果是新的指數，則將後面的項目往右移，插入正確位置。

例如：

```text
輸入：1 + 4x^3 - 2x + 5x^3 + 2x
整理：9x^3 + 1
```

這讓後續的加法與輸出都能直接使用整理好的資料

### 4.3 `Add()`：多項式加法

加法採用兩個索引 `aPos`、`bPos`，同時走訪 A 與 B：

1. 如果兩邊指數相同，就把係數相加。
2. 如果指數不同，先取指數比較大的項目。
3. 其中一邊走訪結束後，把另一邊剩餘的項目加入答案

```text
A(x) = 3x^2 + 2x + 1
B(x) = x - 1
--------------------
A+B  = 3x^2 + 3x
```

因為項目已經排序，因此不需要在加法過程中重新尋找每一個指數

### 4.4 `Mult()`：多項式乘法

乘法使用雙層 `for` 迴圈，讓 A 的每一項與 B 的每一項相乘：

- **係數相乘**：`cf = A的係數 * B的係數`
- **指數相加**：`ep = A的指數 + B的指數`
- 把乘積交給 `NewTerm()`，自動合併相同次方

```text
(3x^2 + 2x + 1) * (x - 1)
= 3x^3 - 3x^2 + 2x^2 - 2x + x - 1
= 3x^3 - x^2 - x - 1
```

程式不需要為每次相乘另外建立一個完整的多項式，而是直接把乘積項目加入結果物件

### 4.5 `Eval()`：多項式代入計算

`Eval(float f)` 會將 `f` 代入每個項目的 x，使用 `<cmath>` 中的 `pow()` 計算次方，再將各項結果加總

```text
A(x) = 3x^2 + 2x + 1
x = 2

A(2) = 3*(2^2) + 2*2 + 1
     = 12 + 4 + 1
     = 17
```

此函式的回傳型別為題目使用的 `float`，沒有另外實作大數或高精度運算

### 4.6 輸入、輸出運算子多載

**`operator>>`：** 讀取項數，以及每一項的係數與指數。讀取時先建立暫存 `Polynomial`，全部輸入成功後才指定給原物件，避免輸入中途失敗而破壞舊資料

**`operator<<`：** 負責輸出整齊的多項式，並處理：

| 資料內容               | 輸出形式 |
|---                    |---|
| 係數為 1、指數為 3     | `x^3` |
| 係數為 -1、指數為 1    | `-x` |
| 係數為 3、指數為 1     | `3x` |
| 係數為 -2、指數為 0    | `-2` |
| 沒有非零項             | `0` |

### 4.7 輔助輸入函式與操作介面

| 函式                   | 功能 |
|---                    |---|
| `ParsePolynomial()`   | 把一整行文字解析成多項式，並檢查是否有多餘資料 |
| `ReadPolynomial()`    | 顯示輸入提示；格式有誤時要求重新輸入 |
| `ParseFloat()`        | 檢查代入值是否為有效的 `float` 數字 |
| `ReadFloat()`         | 讀取使用者要代入的 x 值 |
| `InteractiveMode()`   | 顯示 0～7 操作選單，依照選項呼叫對應函式 |

## 5. 記憶體管理與設計重點

因為 `termArray` 是使用 `new[]` 配置的動態記憶體，如果直接複製指標，兩個物件可能共用同一塊陣列，造成資料互相影響或重複釋放

為了解決這個問題，程式實作了：

- **建構子**：一開始配置容量為 1 的陣列，`terms = 0` 表示零多項式
- **複製建構子**：另外配置新陣列，再複製每一項資料，避免共用指標
- **賦值運算子**：使用 copy-and-swap 的方式，先產生副本，再交換資料
- **`Swap()`**：交換兩個物件的陣列指標、容量及項數
- **解構函式**：使用 `delete[] termArray` 釋放配置的記憶體

我希望同一個多項式能夠被重複加法、乘法、重新輸入，而不會因為物件複製造成記憶體管理問題

## 6. 效率分析

`m`、`n` 分別代表 A、B 的非零項數，`t` 代表單一多項式目前的項數

| 函式                 | 時間複雜度（大致）              | 原因 |
|---                   |---                            |---|
| `row()`              | `O(t)`                        | 複製原有的 t 個項目 |
| `AppendTerm()`       | 攤銷 `O(1)`                   | 大部分情況直接附加，偶爾需要擴容 |
| `NewTerm()`          | `O(t)`                        | 尋找插入位置，必要時移動後面的項目 |
| `Add()`              | `O(m + n)`                    | 兩個已排序的多項式各掃描一次；包含參數複製的成本 |
| `Mult()`             | 最差 `O((m*n)^2)`             | 有 m×n 次配對相乘，每次 `NewTerm()` 可能掃描已累積的項目 |
| `Eval()`             | `O(t)` 次走訪，另加次方運算成本 | 每項呼叫一次 `pow()` |
| `operator<<`         | `O(t)`                        | 依序輸出每個有效項目 |

`operator>>` 在最差情況下，每次新增項目都可能需要搜尋與移動陣列內容，因此處理 `t` 個輸入項目可能達到 `O(t^2)`

這份程式主要以清楚、可理解的動態陣列與基本運算為設計重點，沒有使用特別複雜的乘法演算法

## 8. 遇到的問題、限制與心得

### 設計時需要注意的地方

1. **同次項的處理：** 如果不先合併相同指數，顯示結果可能出現重複次方，也會讓後續運算比較麻煩。因此使用 `NewTerm()` 統一處理新增、排序與合併
2. **動態記憶體的管理：** 使用指標時必須處理複製和釋放，不能只複製陣列位址，所以加入複製建構子、賦值運算子與解構函式
3. **輸入資料的完整性：** 使用暫存物件，確認輸入成功才更新 A、B，避免錯誤資料破壞原本的內容
4. **輸出格式：** 特別處理係數正負號、係數為 1、指數為 0 或 1 的情況，讓結果更容易閱讀

### 目前的限制

- 係數和代入值使用 `float`，小數可能有精度誤差；運算結果過大時，也可能發生溢位
- 輸入時會檢查係數及代入值是否為有限數字，但加法、乘法和代入運算**沒有全面檢查運算結果是否溢位**
- 乘法時會直接將兩個 `int` 指數相加，沒有額外檢查指數相加是否超過整數範圍
- 雖然輸入項數上限設為 200000，但大量亂序項目會讓插入整理與乘法耗費很多時間，並不代表所有這種規模的輸入都能快速完成
- 一筆多項式必須在同一行輸入；目前不支援直接輸入 `3x^2+2x+1` 這種完整數學式
- 程式使用繁體中文提示；在部分 Windows 主控台中，若編碼設定不一致，仍可能顯示中文亂碼
